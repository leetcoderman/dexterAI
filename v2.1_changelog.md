# ModelForge (dexterAI) v2.1 Updates Changelog

*This document summarizes the updates, feature additions, and bug fixes implemented after Phase 6 of the v2 requirements.*

## 1. Global UI Zoom (Browser-Style Scaling)
A robust scaling engine was implemented to allow users to zoom the entire interface, similar to standard web browsers.

- **Native Scaling:** Replaced earlier fixed-resolution CSS and root `font-size` approaches with Electron's native `webFrame.setZoomFactor()`. This scales *everything* uniformly across the renderer, including text, padding, grid containers, and SVG elements, preventing layout breakage. *(Files: `apps/desktop/src/renderer/src/App.tsx`, `apps/desktop/src/preload/index.ts`, `apps/desktop/src/preload/index.d.ts`)*
- **Keyboard Shortcuts:** Added global keyboard shortcuts (`Cmd/Ctrl + =/+, -, 0`) to zoom in, zoom out, and reset. *(File: `apps/desktop/src/renderer/src/App.tsx`)*
- **Main Process Menu Override:** Created a custom Electron Application Menu with zoom accelerators. This handles `Cmd+-` natively in the main process and passes the commands to the renderer via IPC (`zoom:change`), bypassing Electron's default shortcut interception. *(File: `apps/desktop/src/main/index.ts`)*
- **Settings Sync:** Added a "Global Zoom Level" percentage dropdown in the Settings screen that remains perfectly synced with keyboard shortcut actions. State is persisted via `Zustand`. *(Files: `apps/desktop/src/renderer/src/screens/Settings.tsx`, `apps/desktop/src/renderer/src/store/index.ts`)*

## 2. UI & Accessibility Enhancements
Significant refinements were made to the overall chat interface and side navigation.

- **Sidebar Collapse Toggle:** Added a toggle button (`PanelLeftClose` / `PanelLeftOpen`) in the sidebar header. The sidebar can now collapse into a minimal, icon-only rail (`w-14`), saving screen real estate. *(Files: `apps/desktop/src/renderer/src/components/layout/Sidebar.tsx`, `apps/desktop/src/renderer/src/store/index.ts`)*
- **Portal-Based Settings Tooltip:** The informational tooltip on the "Temperature" slider was previously clipping due to `overflow-y: auto` boundary constraints. It was completely rewritten using a React Portal (`createPortal`) rendered directly into `document.body` with `position: fixed`. This allows the tooltip to float cleanly over the sidebar boundary and conversation screen without clipping. *(File: `apps/desktop/src/renderer/src/components/chat/SettingsDrawer.tsx`)*
- **Icon Refactoring:** Corrected an invalid import error by replacing the deprecated `Layers` icon with `ListTree` from `lucide-react`. *(File: `apps/desktop/src/renderer/src/components/layout/Sidebar.tsx`)*

## 3. Critical Bug Fixes & Refinements
- **Max Tokens Default & Parsing Fix:** 
  - Increased the internal default maximum tokens from 1024 or 2048 to **8192** across all AI provider adapters (OpenAI, Anthropic, Google, NVIDIA) to ensure long-form code generation isn't accidentally cut off. *(Files: `apps/desktop/src/main/adapters/openai.adapter.ts`, `anthropic.adapter.ts`, `google.adapter.ts`, `nvidia.adapter.ts`)*
  - Fixed an issue where clearing the Max Tokens input field evaluated `parseInt('')` to `NaN`, instantly resetting the value. Implemented string-to-number safe parsing on blur. *(File: `apps/desktop/src/renderer/src/components/chat/SettingsDrawer.tsx`)*
- **Memory Persistence Bug Fix:** 
  - Identified an issue where clicking "Save" in the Settings Drawer was fully overwriting the `settings_json` database column instead of merging it. This was accidentally wiping out the internal `_memoryExtracted: true` flag, breaking the conversational memory sub-system. It has been corrected to cleanly merge user settings with internal application flags. *(Files: `apps/desktop/src/renderer/src/components/chat/SettingsDrawer.tsx`, `apps/desktop/src/main/ipc/chat.ipc.ts`)*
- **AI Assistant Empty String Issue:** Addressed streaming bugs where empty string chunks or malformed JSON payloads from the provider adapters interrupted the frontend Markdown rendering pipeline. *(Files: `apps/desktop/src/renderer/src/components/chat/MessageBubble.tsx`, `chat.ipc.ts`)*
