# DexterAI v3.11 🚀

DexterAI is a premium, open-source AI development workspace designed to provide a VS Code-like experience for interacting with cutting-edge AI models.

## ✨ Latest Features (v3.11)

- **Premium Code Workspace**: A redesigned layout featuring a VS Code-inspired Activity Bar and Sidebar hierarchy.
- **Multi-Root Workspace Support**: Open and manage multiple project folders simultaneously.
- **Explorer Context Menus**: Desktop-class right-click support for file operations (New File, New Folder, Rename, Delete).
- **Integrated Model Catalogue**: Support for **NVIDIA NIM**, OpenAI, Anthropic, Google Gemini, and more.
- **System Reveal**: One-click "Reveal in Finder/Explorer" integration.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- pnpm

### Installation
```bash
pnpm install
```

### Development
```bash
pnpm dev
```

### Build
```bash
# Build for Mac
pnpm run build:mac

# Build for Windows
pnpm run build:win
```

## 🌌 Core Components

- **Activity Bar**: Navigate between Explorer, Search, and Chat.
- **File Explorer**: Lazy-loading directory trees with full CRUD support.
- **Code Chat**: Context-aware AI assistant with tool-calling capabilities.
- **Terminal**: Integrated system terminal for seamless development.
